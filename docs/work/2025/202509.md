- react 记忆化的组件：当 props 没有改变时跳过重新渲染 ：React 通常在其父组件重新渲染时重新渲染一个组件。你可以使用 memo 创建一个组件，当它的父组件重新渲染时，只要它的新 props 与旧 props 相同时，React 就不会重新渲染它。这样的组件被称为 记忆化的（memoized）组件。

要记忆化一个组件，请将它包装在 memo 中，使用它返回的值替换原来的组件：

```js
const Greeting = memo(function Greeting({ name }) {
  return <h1>Hello, {name}!</h1>
})

export default Greeting
```

- CORS 中的简单请求

:::info

如何判断：记住三个条件
一个请求要想成为“简单请求”，必须 ​​ 同时满足 ​​ 以下三个条件：

- 1.方法是指定的三种之一 ​​：GET、HEAD 或 POST。
- 2.请求头字段仅包含安全字段 ​​：如 Accept、Accept-Language、Content-Language、Content-Type、DPR、Downlink、Save-Data、Viewport-Width、Width 等。
- 3. ​​Content-Type 的值是指定的三种之一 ​​（如果设置了该头）：text/plain、multipart/**form-data** 或 application/**x-www-form-urlencoded**。

只要有任何一条不满足，浏览器就会将其判定为“复杂请求”

- 什么时候会触发**回源**操作: 从源站获取文件到缓存节点。“回源”是 ​​ 内容分发网络（CDN）​​ 中的术语。CDN 的目的是将您的文件（音频、视频等）缓存到全球各地离用户最近的服务器节点上，让用户能最快地访问到资源。

:::info

### 回源的发生场景：​​

​1.​ 缓存失效 ​​：CDN 节点上的文件缓存时间到期了。

​​2.缓存缺失 ​​：请求的文件在这个 CDN 节点上是第一次被访问，没有被缓存过。

​3.​ 手动刷新 ​​：您在后台更新了音频文件，主动告诉 CDN 去清空缓存并重新回源拉取最新文件。

### 一个典型的流程是：

1.您将音频文件上传到腾讯云 COS 的 ​​ 存储桶 ​​（源站）中。

2.您在 CDN 服务中配置，将 ​​ 源站地址 ​​ 指向这个存储桶的地址。

3.您将企微工作台里的音频链接地址，改为 CDN 提供的加速域名。

4.企业微信用户访问音频时，请求会到达离他最近的 CDN 节点。

5.CDN 节点 ​​ 回源 ​​ 到您的 COS​​ 存储桶 ​​ 获取文件，缓存后返回给用户。

对于您遇到的 CORS 问题，配置的地方就在 ​​ 存储桶 ​​ 的权限管理里（或者如果用了 CDN，有时也需要在 CDN 配置中设置响应头），允许 https://work.weixin.qq.com这个“Origin”来访问资源

### render props

- 定义
  “render prop”是指一种在 React 组件之间使用一个值为**函数**的 **prop 共享代码**的简单技术。——React 官方，值为函数，porp 共享
- 示例

```js
import React from "react"
const RenderChildren = (props) => {
  return <React.Fragment>{props.children(props)}</React.Fragment>
}
```

- render Props 前提

#### render props  的载体应该是一个 React 组件，这一点是与高阶组件不同的（高阶组件本质是函数）；

#### render props  组件正常工作的前提是它的子组件需要以**函数形式**存在。

### 理解 render props 的灵活之处

render props 和高阶组件一个非常重要的区别，在于对数据的处理上：在高阶组件中，目标组件对于数据的获取没有主动权，数据的分发逻辑全部收敛在高阶组件的内部；而在  render props  中，除了父组件可以对数据进行分发处理之外，子组件也可以选择性地对数据进行接收

- 生成临时下载链接

```js
function downloadData(data, filename, type = "text/plain") {
  const blob = new Blob([data], { type })
  const url = URL.createObjectURL(blob)
  const a = document.createElement("a")
  a.href = url
  a.download = filename
  document.body.appendChild(a)
  a.click()
  // 清理很重要！不然会内存泄漏
  setTimeout(() => {
    document.body.removeChild(a)
    URL.revokeObjectURL(url)
  })
}
```
