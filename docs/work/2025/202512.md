- iOS 系统对于通过 JavaScript 动态创建的 <input type="file">元素有特殊要求：必须将其实际添加到 DOM 树中，其 change 事件才能被正常触发。您的代码中使用了 input.click()，但可能缺少了添加到 DOM 的步骤。

```js
// 创建input元素
const input = document.createElement("input");
input.type = "file";
input.accept = uploadAcception[resourceType];
// 关键一步：将input元素添加到body中
document.body.appendChild(input); // [5](@ref)

input.onchange = async (event: any) => {
  // ... 您的处理逻辑 ...

  // 事件处理完成后，从DOM中移除input元素
  document.body.removeChild(input); // [5](@ref)
};

input.click();
```
