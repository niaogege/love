- package.json 中的配置**resolutions**字段定义
  ::: info

package.json 中的 resolutions 字段是一个强大的工具，主要用来强制统一项目中某个包的版本，无论这个包是直接依赖还是被其他依赖包间接引入的（即嵌套依赖或间接依赖）。它让你能绕过包管理器默认的依赖解析规则，直接干预版本选择。

### pnpm 中的定义

对于 pnpm，语法类似，但字段通常放在 pnpm.overrides 中（resolutions 是其别名）：

### resolutions 的工作原理是在包管理器（如 Yarn 或 pnpm）进行依赖解析时，强制将匹配规则的依赖覆盖为你指定的版本 。其语法非常灵活，允许你进行不同粒度的控制。

```json
{
  "resolutions": {
    "react": "18.2.0", // 全局统一React版本
    "webpack@^4.0.0": "5.0.0", // 将特定版本的webpack依赖升级
    "parent-package>child-package": "4.0.0"// 仅重写 parent-package下的 child-package，不影响其他包下的
  }
}
``

:::
```
